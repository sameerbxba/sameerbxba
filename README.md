Waterloo Electrical Engineering, 2026. Five co-op terms across strategy, delivery and analytics at Equitable Life, Seaspan, OLG and Vectonium. What I build now is governance tooling, and every project turns on the same question: what should a system be stopped from doing?

**Three things worth opening**

- [soc2-gap-agent](https://github.com/sameerbxba/soc2-gap-agent): an agent that reviews a vendor's SOC 2 report against your own control requirements. It cannot write without a person approving that specific write, and it cannot record a finding it cannot quote verbatim. Runs end to end with no API key.
- [portfolio-attestation](https://github.com/sameerbxba/portfolio-attestation): a quarterly attestation cycle for an application register. Eight controls decide what counts. The recorded quarter returns a 90 percent response rate and 23 percent coverage, and the gap is the finding.
- [SyncBase](https://github.com/sameerbxba/syncbase): an alignment hub for product managers with one model-backed feature, and a NIST AI RMF assessment of it that turned up a control I had marked as implemented that did not exist.

Case studies and both governance documents are at [sameerbxba.github.io](https://sameerbxba.github.io). I am on [LinkedIn](https://www.linkedin.com/in/sameer-athili).
